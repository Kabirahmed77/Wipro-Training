Steps for creating to do list application using html,css and js( external js file)
    1. Create a form with an input field and a submit button.
    2. Add an event listener to the form that listens for the submit event.
    3. When the form is submitted, prevent the default behavior and get the value of the input field.
    4. Create a new list item element and set its text content to the value of the input field.
    5. Append the new list item to an unordered list element on the page.
